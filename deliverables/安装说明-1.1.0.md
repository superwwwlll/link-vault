# 链藏 1.1.0 安装与升级

1. 桌面上的 `lian-cang-1.1.0-debug.apk` 是新版。传到 Android 8.0 及以上手机，点击安装。
2. **已有第一版时直接覆盖安装，不要卸载、不要清除数据。** 包名/签名一致，数据库保持兼容；旧APK保留。
3. 系统提示时给文件管理器临时允许“安装未知应用”，装好可关闭。
4. 首次升级后先进入「设置 → 导出收藏」，将全部收藏保存为JSON。第一版没有导出功能；以后升级前先备份。
5. 新版分「收藏 / 标签 / 设置」三个底栏；点卡片进详情，右上角编辑；编辑时可以点选已有标签。
6. 导入路径：「设置 → 导入备份 → 检查预览 → 确认合并」。最多10MB/10000条，重复跳过、不覆盖原有内容。

备份为未加密JSON；系统选择器可能提供云盘，请自行选择位置并妥善保管。卸载/清除数据会丢失本地收藏，系统自动备份仍关闭。
