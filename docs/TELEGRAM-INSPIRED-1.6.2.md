# 1.6.2 紧凑交互优化任务

借鉴 Telegram 的信息层级和反馈方式，不复制品牌、不把文章阅读强制改成聊天。

## 独立任务（已完成并整合）

1. 收藏密度：默认紧凑列表，舒适卡片可切换，选择保存在本机。
2. 固定标题与搜索：滚动后仍可搜索，状态筛选有明确选中指示，标签保留二级筛选。
3. 多选：长按进入，顶部批量操作，返回退出，选中期间隐藏新增按钮。
4. 单条操作：底部面板提供复制、分享、编辑、归档等操作，删除仍确认。
5. AI 对话：独立页面，底部输入栏随输入法；总结按文档阅读，追问按消息阅读。
6. AI 反馈：发送/等待/停止/失败重试明确，失败不丢输入，不自动重复计费请求。
7. 设置与视觉：标准分组行、当前值、图标导航和克制强调色；保留必要隐私提醒。
8. 删除撤销：只撤销当前成功删除的条目，不复活永久删除的数据，不覆盖较新的删除操作。
9. 集成审查：路由、Back、密钥、私密笔记、窄屏/大字号/深色、自动化与正式签名。

验收：269 项测试通过；独立审查发现并修复草稿返回、忙碌撤销、外部分享及 HTML 暂存边界。详见 [验证报告](../VERIFICATION-1.6.2.md)。

## 验收边界

- 数据库 schema、包名、签名保持不变；不擅自覆盖标题/正文。
- 私密笔记仍不参与 AI；操作界面变化不等于增加上传授权。
- AI 记录与未应用建议仍不进入备份。接口计费和进程退出中断请求的边界不变。
- 自动化使用模拟响应和 Robolectric 原生渲染，不消耗用户 API 额度，不代替实机验收。
