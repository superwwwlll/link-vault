# 1.6.1 页面优化任务与验收

目标：保留字号、数据和现有功能，让用户更快找到收藏和配置入口。依据用户提供的真实长标题、多标签和设置截图，不以缩小所有字体掩盖布局问题。

## 单任务（已完成并集成）

1. 收藏顶部：搜索进入标题区，结果数量优先，次要操作收入更多菜单。
2. 收藏卡片：标签单行、溢出计数、来源文字、可辨识的 AI 摘要与任务状态；原标题和正文不改写。
3. 标签页：紧凑列表、长名称换行、数量与菜单对齐、排序和合并入口。
4. 设置导航：设置首页只保留简明分类，详情进入可返回的子页。
5. AI 接口：紧凑服务商选择、密钥显隐、测试与验证结果集中、地址高级设置。
6. 阅读助手：关注方向引导、模板编辑和删除确认、自动分析当前状态与计费提醒。
7. 翻译说明：共用接口关系清晰，必要隐私和费用信息常驻，技术细节按需展开。
8. 集成审查：普通字号、窄屏大字号、深色模式、导航返回、保存数据、测试及正式签名验证。

验收结果：241 项测试在完整构建及强制重跑中通过；lint 0 errors，10 个现有依赖升级提醒。详见 [验证报告](../VERIFICATION-1.6.1.md)。

## 不变的边界

- 不迁移或删除收藏/笔记数据，不自动覆盖手动标题。
- 私密笔记不上传 AI；自动分析仍由用户控制，批量分析可能逐条计费。
- 已确认应用的标题和标签进入普通收藏备份；AI 总结、对话和未应用建议仍只保存在本机，不进入备份。
- 原签名覆盖升级，保留历史更新下载文件名。

## 验收方法

- 使用与用户截图相近的长中英混排标题、长标签和五个以上标签，不只使用短演示内容。
- 以 Compose 真实交互断言和 Robolectric 原生渲染截图检查，明确这不等于手机实机验收。
- 检查设置子页返回、修改密钥/模型后验证失效、标签排序及合并确认。
- 完整运行单元测试、lint 和 release 构建；核对签名、非调试 Manifest、版本号及发布文件 SHA-256。
