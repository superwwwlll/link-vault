# 链藏 1.6.1

针对真实长标题、多标签和大字号场景改善页面布局。

- 收藏页压缩顶部，搜索与常用操作更集中；标签不再把列表卡片撑成多行。
- 收藏卡片展示清晰来源及 AI 分析反馈，AI 摘要与网页描述区分；不自动覆盖原标题。
- 标签页改为紧凑列表，改善长名称显示、排序与标签管理。
- 重命名与合并标签使用独立编辑页，确认前不改数据，返回可放弃编辑；归档标签也会正确合并。
- 设置页拆分为分类子页，AI 接口、阅读助手和翻译不再挤在一条长页面里。
- 接口配置集中连接测试与验证状态；密钥支持显隐，地址保留可编辑高级配置。
- 关注方向与模板操作更清楚，删除模板需确认；必要隐私/计费提醒保留，详细说明按需展开。
- 修复列表加载旧 AI 记录与新分析竞争，避免成功结果被旧记录覆盖或取消后丢失旧总结。

**直接覆盖安装，不要卸载或清除数据。** 沿用原签名，版本 build 25；升级前建议导出备份。
