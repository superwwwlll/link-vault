# AI 阅读助手（1.6.1）

## 使用

1. 设置 → AI 接口：默认 DeepSeek，地址和模型名已填好；填入自己的 **API Key**。
2. 点击「测试连接」。实际短请求成功后显示「验证通过」，不发送收藏内容；测试也可能计费。
3. 设置 → 阅读助手：填写「我的工作、兴趣与关注方向」，选择分析模板；点击「编辑模板」修改名称与提示词。删除模板需要确认。
4. 可开启「保存后自动分析」。关闭时仍能在收藏详情或已保存的普通笔记编辑页手动分析。
5. 总结下方输入问题继续对话。重进同一条内容仍可继续聊。
6. 链接收藏分析成功后同时生成标题和 1–5 个标签建议。点击「应用标题与标签」并确认才替换标题、追加标签；不自动覆盖已有内容，普通笔记暂不支持该建议。

默认模板：快速阅读、工作应用、研究分析。可改名称/提示词、增加/删除模板，至少保留一个。
已有对话沿用生成总结时的关注方向与框架；重新分析成功后才替换总结和清空旧对话，失败保留旧记录。

## 数据和费用边界

- 自动分析默认关闭，首次开启要求连接验证通过并确认上传和费用提示。
- 自动分析只由新保存/编辑保存触发，不扫描旧收藏、备份导入或剪贴板；批量保存的新链接也会分析并可能逐条计费。
- 链接使用本机正文快照；没有正文时仅在「页面信息抓取」已开启且网址为 https 时抓取。不用标题/网址假装读过原文。
- 普通笔记发送已保存正文；私密笔记没有上传路径。普通笔记改成私密时取消未完成分析并删除已有本机 AI 记录；已经发送到服务商的内容无法撤回。
- 上传包含正文、标题、链接、收藏备注、关注方向、提示词框架；追问还包含问题、总结与最近对话。密钥只用于认证，不进入提示词或记录。
- 每篇材料最多取前 24,000 字，截断会明确提示；每次追问带最近最多 6 轮完整问答，总历史预算 12,000 字，总结最多提供前 6,000 字。更早记录仍保留在本机，但模型当轮不能看到。
- AI 请求逐条排队，不无限并行。可取消；关闭自动分析会取消待处理的自动请求，不取消你手动发起的请求。请求已到达服务商时仍可能计费。
- 使用当前应用进程的协程，进程退出会中断；不承诺关掉应用后后台继续完成，也不自动重试收费请求。
- 正文变化时旧对话不能继续，先重新分析；网络返回后再次校验正文，删除/加密/内容变化时旧结果不会落盘。
- 总结、对话和生成时的提示词放在应用私有 `files/analysis/`；**目前不进 JSON 或加密备份**。模板/关注方向为本机设置，也不进备份。卸载或清除应用数据会丢失。
- API Key 沿用原有本机 SharedPreferences 存储（明文），不进备份；沿用 https、禁止跨域重定向等网络边界。
- 删除笔记或永久删除收藏会清理 AI 记录；收藏软删除后记录随回收站保留，30 天清理时一起删除。
- AI 输出只是分析，不是事实核验；提示词要求区分原文事实、推断与建议，但不能保证模型永不出错。
- 建议标题最多 120 字，标签每个最多 24 字；服务返回格式不正确时不写入新总结/建议，已有记录保留。应用建议不调用 AI、不再计费，保留原文、备注、已有标签和收藏状态。
- 建议生成后若收藏正文/标题/备注/URL 已变化，禁止应用旧建议，要求重新分析；应用标题后更新对话的内容指纹，仍可继续追问。
- 确认应用后的标题/标签属于普通收藏数据，照常进入收藏备份；未应用的 AI 建议、总结和对话仍不进入备份。

## 验证

`AnalysisTest` 覆盖请求格式、截断、对话历史预算、持久化、自动开关、重复内容不重复调用、追问保留框架、修改正文拦截、失败保留旧结果、未验证/私密拒绝上传、转私密时取消清理、缺正文不猜测、模板持久化、接口预设及错误处理。

`AnalysisVisualTest` 用模拟服务响应真实操作 Compose 界面：填写密钥 → 测试通过 → 编辑关注方向 → 手动总结 → 多轮追问，并生成 Android 原生渲染截图（非真机截图）。无真实密钥，不对商业 API 进行付费实测。
