## 链藏 1.6.0 · AI 阅读助手

- 保存链接和普通笔记后可自动分析「讲了什么、哪些值得关注、为什么」，独立开关，默认关闭。
- 总结下可围绕原文继续对话；总结和对话保存在本机，重进条目仍可接着聊。
- 链接分析后同时生成标题和标签建议，**确认后才应用**：替换标题、追加标签，保留原文、备注和已有标签。普通笔记暂不支持标题/标签建议。
- 设置个人工作/兴趣/关注方向，切换、编辑或新增提示词框架，内置快速阅读、工作应用、研究分析。
- 默认 DeepSeek，预填 API 地址与模型名；另有智谱 GLM、通义千问、Kimi、硅基流动、OpenAI 和自定义接口。
- 填入自己的 API Key，测试连接通过后即可分析；附官方开通/充值入口。切换服务商清除旧密钥，修改配置后重新验证。
- 保留搜索图标展开、自动聚焦，以及文字页签切换；修复分析中再次保存最新正文漏处理、旧抓取覆盖已编辑条目的竞态。

### 隐私与费用

AI 会把正文、标题、链接、备注、关注方向和提示词发给你配置的服务商；追问还会发送最近对话，可能计费。
测试连接发送一条短请求，不发送收藏。API 额度通常不包含在聊天会员或编码套餐中。

**私密笔记不上传**；普通笔记改为私密时清除本机 AI 记录并取消未完成分析，但无法撤回已发给服务商的内容。
材料最多取前 24,000 字，超出明确提示；每次追问携带最近最多 6 轮完整问答，历史预算 12,000 字。
**AI 总结/对话和模板暂不进入备份**；卸载、清除数据会丢失。应用进程退出会中断未完成请求，可手动重试。

### 安装与验证

**直接覆盖安装，不要卸载或清除数据。** 升级前先导出收藏 JSON；有私密笔记时另导出 `.lvault` 加密备份。

- 包名 `cn.linkvault`；versionCode **24**；Android 8.0+。
- 沿用原签名，正式 release 构建，关闭调试并启用代码/资源收缩；数据库仍为 v5，无新迁移。
- 自动测试、界面交互测试、lint 和正式构建验证通过；商业 API 与用户手机安装仍需填入自己的密钥/实机验收。
- 发布资产名 `lian-cang-debug.apk` 为兼容历史更新机制保留，实际为正式 release 包；SHA-256 与签名指纹见随包 `latest.json`。
