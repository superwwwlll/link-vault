OpenSI Serif in this app
=========================

Source: https://github.com/auraunii/opensi-fonts/releases/download/release/OpenSI-Serif-and-Mono.zip
Family name in the file: OpenSI Serif
This is the open-source font recommended in a public post. It is not Anthropic Sans, Anthropic Serif, Anthropic Mono, or an official Claude font.

What this build contains
- Latin, digits, and punctuation already present in OpenSI Serif Regular keep those outlines.
- Characters OpenSI Serif does not include, including Han, come from the existing Noto Serif SC GB2312 subset (weight 500).
- OpenSI Mono is not bundled. The download does not state a license for Mono.

Licenses
- Serif: SIL Open Font License 1.1, see OFL-OpenSI-Serif.txt and FONTLOG-OpenSI-Serif.txt.
- Han subset: SIL Open Font License 1.1, see OFL-NotoSerifSC.txt.
  Noto Serif SC uses Reserved Font Name "Source". This file is not named Source or Noto.
